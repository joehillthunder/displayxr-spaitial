# SpAItial Worlds

Real rooms, scanned with an iPhone and rebuilt by [SpAItial](https://spaitial.ai/)'s **Echo-3** world model,
shown as glasses-free 3D dollhouses on a DisplayXR display, and in 2D in any other browser.

- **3D viewer:** https://joehillthunder.github.io/displayxr-spaitial/ (six Echo-3 gallery rooms, cut away
  at 1.6 m, drag to turn, measure in metres, depth −/+, full panel). `?world=<id>` opens one room.
- **About:** https://joehillthunder.github.io/displayxr-spaitial/about/ covers Echo-2 / Echo HQ / Echo-3,
  the Developer API flow, export formats and pricing.

Captures © SpAItial, streamed from SpAItial's servers (Streamed SOG) and not hosted here; `thumbs/` holds
gallery thumbnails for the About page. Terms for public use are not yet confirmed with SpAItial.
