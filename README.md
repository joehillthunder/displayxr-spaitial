# displayxr-spaitial

A showcase of [SpAItial](https://spaitial.ai/)'s Echo world models (Echo-2, Echo HQ, Echo-3) for DisplayXR HQ: a splat-style parallax preview, eight gallery worlds, the Developer API flow, export formats and pricing.

Live: https://joehillthunder.github.io/displayxr-spaitial/

- Single static `index.html`, no build, no keys. Runs in 2D in any browser.
- `thumbs/` are thumbnails from SpAItial's public gallery (https://spaitial.ai/gallery), © SpAItial. Terms for reuse are not yet confirmed with SpAItial; remove them if asked.
- Facts compiled 2026-11-25 from spaitial.ai and docs.spaitial.ai.

Linked from [DisplayXR HQ](https://joehillthunder.github.io/) (AI wing).
