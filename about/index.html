Developer API · api.spaitial.ai/v1

From prompt to splat in three calls

Generation is asynchronous. Submit a request, poll its status (or register a webhook), then fetch the world. The response includes a hosted viewer_url.

1 · submitPOST /v1/worlds

Returns a request_id.

2 · waitGET /v1/worlds/requests/{id}/status

Poll, or receive a webhook when done.

3 · fetchGET /v1/worlds/requests/{id}/splat

302 to a signed download URL, valid 5 minutes.

# Key from developers.spaitial.ai/api-keys (spt_live_…)
curl -X POST https://api.spaitial.ai/v1/worlds \
  -H "Authorization: Bearer $SPAITIAL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "echo-2",
    "title": "Night market under neon signs",
    "output_format": "spz",
    "input": {
      "type": "text",
      "prompt": "A narrow night market street, neon signs, wet pavement, steam from food stalls"
    }
  }'

# → { "request_id": "…" }  then poll:
curl https://api.spaitial.ai/v1/worlds/requests/$REQUEST_ID/status \
  -H "Authorization: Bearer $SPAITIAL_API_KEY"

Also on the API: image upload (POST /v1/files), mesh, simplified-mesh, floorplan and zip exports, reconstructed capture cameras for Echo-3, and GET /v1/models. A hosted MCP server at mcp.spaitial.ai/mcp lets coding agents such as Claude Code call it directly.
